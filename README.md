# ยิงเลขบวก (Addition Gun Game)

เกมฝึกบวกเลข 2 หลัก ที่ใช้ **มือทำท่าปืน** เล็งและยิงคำตอบผ่านกล้องเว็บแคม
แต่ละข้อมี 4 ตัวเลือก เล่นทั้งหมด 10 ข้อ

**เล่นได้เลยที่ https://addition-game-eight.vercel.app** (ทั้งคอมและมือถือ)
เว็บนี้อัปเดตเองทุกครั้งที่โค้ดใน branch `main` เปลี่ยน

## วิธีเล่น

1. **ทำท่าปืน** ชูนิ้วชี้ ยกนิ้วโป้งขึ้น กำนิ้วที่เหลือ
2. **เล็ง** ขยับปลายนิ้วชี้ไปที่เป้าคำตอบ (เป้าจะมีขอบสีเหลืองเมื่อเล็งโดน)
3. **ยิง** พับนิ้วโป้งลงเร็วๆ เหมือนสับนกปืน

ถ้าพับนิ้วโป้งแล้วยิงไม่ค่อยติด เลือกโหมด **"เล็งค้างไว้"** ที่หน้าแรก: แค่เล็งค้างที่เป้า 1.5 วินาทีก็ยิงเอง

ไม่มีกล้องก็เล่นได้: กด **"เล่นด้วยเมาส์ / แตะจอ"** แล้วคลิกหรือแตะที่คำตอบ (หรือกดปุ่ม 1-4 บนคีย์บอร์ด)

### การให้คะแนน

- ตอบถูกได้ 100 คะแนน
- โบนัสความเร็ว สูงสุด 50 คะแนน (ยิ่งตอบเร็วยิ่งได้มาก)
- โบนัสตอบถูกต่อเนื่อง +10 ต่อข้อ สูงสุด 50 คะแนน
- จบเกมได้ดาว 1-3 ดวงตามจำนวนข้อที่ถูก และจำสถิติคะแนนสูงสุดไว้ในเครื่อง

ตัวเลือกผิดจะเป็นคำตอบที่เกิดจากความผิดพลาดที่พบบ่อย เช่น ลืมทด หรือหลักสิบผิด จึงต้องบวกจริงถึงจะตอบถูก

## เปิดเกม

เกมเป็นหน้าเว็บธรรมดา ไม่ต้องติดตั้งอะไร

**แบบที่ 1: ดับเบิลคลิก `index.html`** แล้วเปิดด้วย Chrome หรือ Edge กดอนุญาตให้ใช้กล้องเมื่อเบราว์เซอร์ถาม

ถ้าเบราว์เซอร์ไม่ยอมเปิดกล้องจากไฟล์ในเครื่อง (เช่น Safari บางรุ่น) ให้ใช้แบบที่ 2 หรือ 3 แทน เพราะเบราว์เซอร์จะยอมเปิดกล้องให้เว็บที่เป็น `https://` หรือ `localhost` เสมอ

**แบบที่ 2: เปิดผ่าน local server** (ต้องมี Python ซึ่งมีในเครื่อง Mac/Linux อยู่แล้ว)

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000 ใน Chrome, Edge, Safari หรือ Firefox

**แบบที่ 3: เปิดเป็นเว็บผ่าน GitHub Pages** (เล่นได้ทั้งคอมและมือถือ)

1. merge โค้ดเข้า branch `main`
2. ไปที่ repo บน GitHub > **Settings** > **Pages**
3. ตรง **Source** เลือก `Deploy from a branch`, branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1 นาที เกมจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/Addition-game/`

ต้องต่ออินเทอร์เน็ต เพราะตัวตรวจจับมือ (ประมาณ 17 MB) โหลดจาก CDN ตอนเปิดเกมครั้งแรก

## เคล็ดลับให้ตรวจจับมือได้ดี

- นั่งห่างกล้องประมาณ 50-100 ซม. ให้เห็นมือทั้งมือในกรอบภาพมุมล่าง
- ห้องสว่างพอ ไม่มีแสงจ้าอยู่ด้านหลัง
- หันข้างมือหรือหลังมือให้กล้องเห็นนิ้วโป้งชัดๆ
- ดูกรอบกล้องเล็กๆ ตรงกลางล่าง: ข้อความสีเหลือง **"พร้อมยิง!"** แปลว่าเกมเห็นนิ้วโป้งยกขึ้นแล้ว
- ถ้าเกมไปใช้กล้องมือถือแทนกล้องโน้ตบุ๊ก (เช่น Mac ที่ต่อกับ iPhone ผ่าน Continuity Camera หรือ Windows ที่ใช้ Phone Link) ให้เลือกกล้องที่ต้องการจากเมนู **"กล้อง: ..."** ที่อยู่บนกรอบภาพกล้อง เกมจะจำกล้องที่เลือกไว้ให้ครั้งต่อไป (เมนูนี้จะแสดงเฉพาะเมื่อเครื่องมีกล้องมากกว่า 1 ตัว)

ภาพจากกล้องประมวลผลในเบราว์เซอร์บนเครื่องผู้เล่นเท่านั้น ไม่มีการส่งภาพออกไปที่ไหน

## สำหรับนักพัฒนา

ไม่มี build step และไม่มี dependency ตอนรัน ใช้ [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) ตรวจจับจุดบนมือ 21 จุด

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `css/style.css` | หน้าจอเกม |
| `js/questions.js` | สุ่มโจทย์บวกเลข 2 หลัก และตัวเลือกผิดที่ดูสมจริง |
| `js/gesture.js` | แปลงจุดบนมือเป็นท่าปืน ตำแหน่งเล็ง และการยิง (มีค่าปรับความไวใน `CONFIG`) |
| `js/hand-tracker.js` | เปิดกล้องและรัน MediaPipe |
| `js/game.js` | ลำดับเกม คะแนน และเอฟเฟกต์ |
| `js/sound.js` | เสียงประกอบสร้างด้วย Web Audio (ไม่มีไฟล์เสียง) |
| `js/space.js` | สุ่มดาวสำหรับฉากหลังอวกาศ (ดาวเคราะห์ ดวงจันทร์ และดาวตกอยู่ใน `css/style.css`) |

การตรวจท่า:

- **ท่าปืน** = นิ้วชี้เหยียดตรง และนิ้วนางกับนิ้วก้อยงอ (นิ้วกลางจะงอหรือเหยียดก็ได้)
- **ง้าง/ยิง** = ระยะปลายนิ้วโป้งถึงโคนนิ้วชี้/นิ้วกลาง เทียบกับขนาดฝ่ามือ: เกิน `cockThreshold` คือง้างแล้ว ต่ำกว่า `fireThreshold` คือยิง
- ตำแหน่งยิงใช้จุดที่เล็งไว้ตอนนิ้วโป้งเริ่มพับลง (เทียบกับระดับนิ้วโป้งที่ยกสูงสุดของผู้เล่นแต่ละคน) เพราะระหว่างพับนิ้ว มือมักจะตกลงมา
- ขอบบนของจอตรงกับประมาณ 1/4 จากด้านบนของภาพกล้อง ไม่ต้องยกมือสูงระดับตาเพื่อเล็งเป้าแถวบน (`AIM_REGION` ใน `js/game.js`)

กด `D` ระหว่างเล่น (หรือเปิดด้วย `?debug` ท้าย URL) เพื่อดูค่าที่วัดได้จริง ใช้ปรับ `CONFIG` ใน `js/gesture.js` ได้

รันเทสต์ (ต้องมี Node.js 20 ขึ้นไป):

```bash
npm test
```

เทสต์ท่ามือใช้จุดบนมือจริงที่ได้จากการรันโมเดลกับภาพตัวอย่างของ MediaPipe (`tests/fixtures/hands.json`)
